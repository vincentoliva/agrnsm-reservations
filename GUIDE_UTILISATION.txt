AGRNSM – GUIDE RAPIDE

1. Ouvrir index.html pour voir le site public.
2. Ouvrir admin.html pour gérer les contenus.
3. Connexion démo : admin / agrnsm2026

GESTION DES THÈMES
- 13 catégories principales sont déjà créées.
- 41 interventions provenant du fichier Thèmes RNN.xlsx sont intégrées.
- Administration > Thèmes permet de modifier le nom, catégorie, durée, contenu et niveaux.
- « Ajouter » permet de créer une nouvelle intervention.

GESTION DU CALENDRIER
- Administration > Calendrier > choisir une date > Bloquer.
- Les demandes apparaissent comme réservées.
- La version actuelle est un prototype local : pour un vrai site Internet partagé par toutes les écoles, il faudra connecter une base de données.
